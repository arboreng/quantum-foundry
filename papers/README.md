# papers/

Reference papers and citation material backing the algorithms in this repo.
Per-algorithm citations live in each algorithm's `references.bib` (e.g.
[algorithms/shor/references.bib](../algorithms/shor/references.bib)); this
directory is for source material shared across algorithms or too large to
duplicate per-algorithm.

Reserved for that shared material; every citation so far has been
per-algorithm.

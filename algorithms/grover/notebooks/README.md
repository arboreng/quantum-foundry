# Grover notebooks

Exploratory / demo notebooks for Grover's algorithm.

- [grover_demo.ipynb](grover_demo.ipynb) — builds the oracle and circuit for
  a marked item, visualizes it and its measurement histogram, runs
  `search()` end to end (single- and multi-item marked sets). Re-execute
  with:
  ```bash
  uv run jupyter execute --inplace algorithms/grover/notebooks/grover_demo.ipynb
  ```
